# Naveen Harinda

I’m a developer based in Colombo, Sri Lanka, interested in systems programming and search. I learn best by building projects that make me dig into how things work.

## Selected projects

- **[Lanka Trails](https://github.com/imnot-naveen/Lanka-Trail)** — A search tool for hiking in Sri Lanka. It combines SQLite queries and ChromaDB vector search to answer trail questions and uses CLIP to match uploaded photos to locations.
- **[Vita Vault](https://github.com/imnot-naveen/vita-vault)** — A PlayStation Vita troubleshooting knowledge base. Its Python API searches a Qdrant index and returns relevant passages with links to their sources.
- **[Web Server in C](https://github.com/imnot-naveen/web-server-in-c)** — A small HTTP server built with POSIX sockets. It handles GET requests, serves static files, and forks a child process for each connection.
